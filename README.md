# 股票查詢器 — Request function

Python 視窗程式小組報告。本模組負責 **Request function**：向外部 API 發出請求，取得股票資料，再交給分析與繪圖使用。

## 功能

- 查詢股價：當天 / 近三天 / 近一週 / 近一月 / 近一季 / 近一年
- 開盤價、收盤價、成交量
- 三大法人（外資 / 投信 / 自營商）買超賣超與買賣比例
- 可用「股票代號」或「股票名稱」查詢（例 `2330` 或 `台積電`）

## 檔案說明

| 檔案 | 功能 |
|---|---|
| `stock_demo.py` | V1：固定查台積電，印出本月開收量 |
| `stock_demo_v2.py` | V2：可輸入代號或名稱 |
| `stock_demo_v3.py` | V3：可選 6 種期間的開盤 / 收盤 / 成交量 |
| `stock_demo_v4.py` | V4：三大法人（最近交易日） |
| `stock_demo_v5.py` | V5：三大法人依期間，各法人買超賣超與比例 |

## 怎麼執行

1. 安裝 Python 3（建議 3.10 以上）
2. 安裝套件：
   ```
   pip install -r requirements.txt
   ```
3. 執行（以 V5 為例）：
   ```
   python stock_demo_v5.py
   ```
   依畫面提示輸入股票與期間即可。

## 資料來源

- 台灣證券交易所（TWSE）公開 API：開高低收量、三大法人（T86）、股票清單
- FinMind：三大法人歷史資料（可一次取一段期間）

## 分工

- Request function（取得資料）：本模組
- 資料分析（漲跌幅、籌碼、連買連賣）：b 部分
- 圖表（圓餅圖、折線圖）：c 部分
